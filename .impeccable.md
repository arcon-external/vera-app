# Design Context

## Users

PT Arcon Penta Persada quotation staff. They sit at a desk, usually with a
customer inquiry open in another window and a supplier price list in Excel.
They enter line items, optionally add a margin per line, prepare the quote,
check the numbers, and export a PDF. Sessions are short but repeated many
times per day. The job to be done: turn raw costs into a correct, presentable
quotation without arithmetic mistakes and without re-typing data.

## Brand Personality

Precise, composed, official. The interface should feel like a well-kept
ledger: fast to scan, quietly confident, never decorative. Numbers are the
protagonist. The tone is calm and matter-of-fact in copy.

## Aesthetic Direction

Light theme only (the app is used in a bright office, and the quotations
themselves are light documents that must be judged next to the UI).

- Warm-tinted paper neutrals instead of cool slate. The canvas and surfaces
  carry a very low chroma warm hue so the interface reads like paper.
- One accent: a deep teal used sparingly for primary actions and focus. This
  is deliberately cooler and darker than the emerald used for the "profit"
  semantic signal, so action color and success color never blur together.
- Semantic colors reserved for meaning: emerald = profit/success,
  red = failure, amber = "internal only" classification (not a warning).
- Type: native system UI stack for the product chrome (feels like an installed
  desktop tool, load-safe offline), with tabular figures everywhere numbers
  appear and a hand-tuned scale/tracking rhythm. Headings are set in the same
  family but with tighter tracking and heavier weight; no display font.
- Layout: a real application shell with a compact left rail, a wide working
  area for the items ledger, and a sticky summary rail that carries the
  Prepare/Export actions. Density appropriate to data entry.
- Motion: minimal and functional. 150-250ms, transform/opacity only,
  ease-out-quart. Respect reduced motion.

## Anti-references

- Generic SaaS dashboard: cold slate grays, indigo/violet gradients, glass
  cards, glowing buttons, three equal KPI cards.
- Marketing-site treatment of an internal tool: oversized hero headings,
  emoji, decorative badges, centered everything.
- Warning-stripe left borders on callouts.

## Design Principles

1. The number is the interface. Amounts are tabular, right-aligned, and
   never truncated. Labels are quiet; values are not.
2. One accent for action, one for success. Never use the action accent to
   mean "good" and never use the success color on a button.
3. Surface and space before borders. Group with spacing; use a 1px hairline
   only when a boundary is genuinely needed.
4. Every operational state is explicit: idle, loading, ready, error, empty,
   and "internal only" are each visually distinct and never ambiguous.
5. Density is a feature. This is a data-entry tool; keep chrome slender and
   let the ledger breathe horizontally on wide windows.

## Font note

Web fonts are intentionally not used: the desktop build must render offline
with no layout shift, and the native stack matches the platform chrome. The
"avoid Inter/system font" rule from generic web design does not apply to this
installed desktop tool; character is expressed through scale, weight,
tracking, tabular figures, and layout instead.
