# Vera promo ads

Remotion-generated 30-second Apple-style promo in landscape and vertical
formats. The visuals use bold typography, product moments, tactile transitions,
and a restrained black/cream Vera palette.

```bash
npm install
python3 audio/synth.py
npm run render:landscape
npm run render:vertical
```

Outputs are written to `out/` and are intentionally gitignored.
